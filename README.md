New-Pair Radar: a token launch radar that ranks pre-token protocols by the implied value of a token they may one day issue, built around the new-pair signal — a protocol only recently tracked, with no token recorded and fast-moving TVL, scores highest.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
